减少 Claude 用量接口被限流（429）的情况。

- Claude 用量最快每 15 分钟读取一次，这段时间内的刷新复用上次的结果；其他工具的刷新频率不变。
- 被限流后的等待时间按 5、10、20、40、60 分钟逐级加长，并加入随机偏移；服务端的 `Retry-After` 更长时以它为准。
- 冷却状态在 App 重启和 Claude Code 轮换 token 后继续保留；冷却期内的手动刷新不会发出请求。
- 刷新 token 时遇到 429 也会进入冷却。
- 不再在 token 快过期时抢先刷新，交给 Claude Code 处理；只在接口返回 401 时刷新。

适用于 Apple Silicon、macOS 26 及以上。
